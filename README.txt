TP SGA - Systeme de Gestion des Auditoires

Installation :
1. Copier le dossier SGA_TP dans htdocs (XAMPP) ou www (WAMP/LAMP).
2. Lancer le serveur Apache avec PHP.
3. Ouvrir http://localhost/SGA_TP/index.php

Contenu :
- index.php : script principal.
- includes/fonctions.php : toutes les fonctions PHP procedurales.
- data/*.json : donnees d'entree.
- data/planning.txt et data/planning.json : generes au premier lancement.
- data/rapport_occupation.txt : genere au premier lancement.
- formulaires.php : exemple de formulaire de saisie.
- rapports/rapport_SGA.pdf : rapport d'analyse et de conception.
